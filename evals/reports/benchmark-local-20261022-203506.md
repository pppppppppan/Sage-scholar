# Retrieval benchmark
Synthetic topic corpus with multilingual queries. Gold is all chunks in the known topic. Query timing includes query embedding, hybrid retrieval, RRF and same reranker. Corpus embedding is precomputed identically and excluded from index build. RSS includes Python/models/index; cold index load uses a fresh object (OS cache not flushed). One isolated process per backend/size.
