# 细粒度核验规则

1. **身份与内容分开**：DOI/title/author/year 匹配仅确认身份。标题相近、搜索排名高、同一机构不等于同一论文；版本差异可能改变结论。
2. **范围保真**：原文“A 在 Dataset X 条件 C 优于 B”不支持“所有任务全面优于 B”。可降为 partial 并建议改写为带条件的结论。
3. **反向引用**：原文明确显示 B 优于 A，而 Claim 宣称同条件下 A 优于 B，才判 contradicted。指标方向、样本、方法版本和单位必须先对齐。
4. **证据不足**：摘要没有数值不能据此验证精确提升；未在已读范围找到，不等于整篇没有。说明已读范围，并按需回读 Method/Experiments/Appendix。
5. **二手归因**：综述转述某研究，应标明二手来源；未读原作不声称核验原作成功。分别记录原引用和实际可读来源。
6. **组合主张**：分别核验各子句及其来源。多个论文分别证明 A、B，不能推出它们从未验证的因果关系或普遍优势。
7. **输出示例**：Claim｜原引用｜身份 found/unresolved/missing｜supported/partial/contradicted/insufficient/unverifiable｜原文及页节｜原因｜建议。不要把报告原编号误当 Evidence ID；引用新的核验依据时使用工具提供的真实来源 ID。
