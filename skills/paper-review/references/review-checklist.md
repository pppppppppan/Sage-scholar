# 按论文实际内容选择检查项

- **贡献与新颖性**：贡献与摘要是否一致？比较对象是否确实已有？仅了解目标论文时，评价其自述贡献，不断言领域首创。
- **方法与公式**：变量、维度、目标函数、采样分布与训练/推理条件是否明确？论证需要的假设是否在实验满足？给出具体公式或节号，不能用“数学不严谨”替代分析。
- **实验设计**：数据划分和泄漏风险；Baseline 的训练数据、模型规模、预算、调参机会是否可比；指标与任务目标是否一致；随机性、误差范围、显著性（仅适用时）；关键组件的消融和失败案例。
- **图表**：实际读取对应页面/区域，确认坐标、单位、误差条和图例。看不清标记未知；不将不同实验条件的数值直接排名。
- **论证边界**：实验范围能否支持“所有任务”“普遍优于”等广泛表述？负面结果是否被忽略？相关性是否误写成因果性？没有报告不自动判定没做。

建议问题格式：位置 → 作者主张 → 可见证据 → 问题及影响 → 可执行的补充验证。Strengths 同样需要证据，避免套话。来源不足时给出待回答的问题，而非捏造确定性缺陷。
