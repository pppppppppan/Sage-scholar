# Configuration

Host development reads the root `.env`; Docker reads `.env.docker` through Compose `env_file`. Neither is committed or copied into images. Start from the corresponding example rather than copying host paths/proxies into containers.

| Area | Variables / behavior |
|---|---|
| Answering LLM | `LLM_MODEL_ID`; provider key and URL selected by the existing model-prefix adapter. DeepSeek defaults use `DEEPSEEK_API_KEY` and `DEEPSEEK_BASE_URL`; other providers are documented in `.env.example`. |
| Router | `ROUTER_BASE_URL`, `ROUTER_MODEL=qwen3.5:2b`, `ROUTER_TIMEOUT`. Default address trust is loopback only; `ROUTER_ALLOWED_HOSTS` explicitly allows self-managed container/host names. This does not change intent classification or SourcePolicy. |
| Persistence | `SAGE_DATA_DIR`; defaults to repository `data/`. Docker fixes it to `/app/data` for stable saved paths. `SAGE_CONFIG_DIR` chooses host or container MCP configs. |
| Embedding | `EMBEDDING_PROVIDER=local`, `EMBEDDING_LOCAL_MODEL`, `EMBEDDING_DEVICE`, `EMBEDDING_BATCH_SIZE`, `EMBEDDING_LOCAL_ONLY`. Local default: `intfloat/multilingual-e5-small`. |
| Reranker | `RERANKER_MODEL=BAAI/bge-reranker-v2-m3`, device, batch size, max length, local-only flag, cache size; `RERANKER_FALLBACK=rrf` preserves candidate ordering if reranking fails. |
| Visual retrieval | `PDF_VISUAL_ENABLED`, parser (`page` or `docling`), `VISUAL_EMBEDDING_MODEL`, revision/device/local-only; `VISION_MODEL_ID` and image budgets. Docker defaults off and CPU. |
| MCP | `MCP_CONNECT_TIMEOUT`; Tavily key; optional Unpaywall email; HTTP proxy environment. Servers are lazy/capability-scoped. Missing optional tools do not become model capabilities. |
| Budgets | `SAGE_DEEP_RESEARCH_MAX_TOTAL_TOKENS`, report reserve, max ReAct steps; per-agent output/context limits in `.env.example`. Run budget and per-request context window are different limits. |
| Telemetry | `OBSERVABILITY_ENABLED=false`, `LANGFUSE_BASE_URL` (legacy HOST accepted), project keys, explicit model prices. No content export. |

Changing embedding identities/dimensions is not a cache toggle: use the existing index migration/rebuild workflow. Do not reuse old vectors as if they were generated by a new model. Full references: [RAG](rag.md), [observability](observability.md).

Compose file interpolation (`SAGE_WEB_PORT`, `SAGE_BIND_ADDRESS`, `SAGE_DOCKER_VISUAL`) comes from the shell or `docker compose --env-file .env.docker`. Service `env_file` alone only supplies container environment. Default values work with plain `docker compose up -d --build`; advanced build/port overrides are shown in the deployment guide.
